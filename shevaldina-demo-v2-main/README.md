# Демо-сайт: Студия Ольги Шевалдиной — две концепции (Челябинск)

Два самостоятельных сайта (не переключатель тем!). Бюджет запуска: 0 ₽.

## Запуск локально
1. Открой папку `shevaldina-demo` в VS Code.
2. В `img/` лежат ДВА фото: `olga-hero.jpg` (серебро) и `olga-about.jpg` (чёрный портрет).
   Нет файла — покажется заглушка «ОШ» (сайт не ломается).
   Раскладка: тёмный hero = olga-hero; светлый hero = olga-about; светлый «О враче» = olga-hero.
3. Двойной клик по корневому `index.html` → страница выбора → кликай вариант.
   Рекомендую расширение **Live Server** (правый клик → Open with Live Server).

## В чём разница (для объяснения Ольге)
- **Dark Luxury / «Чёрный бархат»** — Editorial/люкс. Прайс как меню ресторана (строки с
  лидерами), full-bleed фото, Cormorant Garamond + Jost. Запись через телефон/консультацию —
  VK-кнопки НЕТ намеренно (в люксе соцвход удешевляет вид).
- **Soft Editorial / «Пудра и графит»** — тёплый журнальный премиум. Кремовый фон, терракота,
  Lora + Golos Text (Paratype, кириллица), прайс в «меню-карточках», таймлайн визита, слоты
  (день → время), вход через VK и личный кабинет с историей заявок.

Оба сайта читают ОДИН файл данных `services.js` (в корне). Заявки изолированы префиксами
`dl_` и `se_` в localStorage, поэтому на одном домене не мешаются.

## Бесплатная публикация (0 ₽) — GitHub Pages
1. github.com/new → имя `shevaldina-demo` → Public → БЕЗ README/gitignore/license → Create.
2. «uploading an existing file» → перетащи ВСЁ СОДЕРЖИМОЕ папки `shevaldina-demo`
   (index.html, services.js, img/, dark-luxury/, soft-editorial/, README.md) — В КОРЕНЬ репо,
   не саму папку. Commit.
3. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save.
4. Ссылка: `https://<логин>.github.io/shevaldina-demo/` — страница выбора.
   Варианты: `/dark-luxury/` и `/soft-editorial/`.
